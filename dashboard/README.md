# Power BI Dashboard

This folder contains the Power BI dashboard developed for the project **Exploring Urban Transport Performance Through Data**.

## File

`Dar_es_Salaam_Urban_Mobility_Dashboard.pbix`

## Dashboard Overview

The dashboard was developed using Power BI to explore and present the simulated urban mobility dataset. It contains three pages:

1. **Performance Overview** – Compares travel performance across the selected transport modes.
2. **Cost and Performance** – Examines transport costs, average cost per kilometre and performance indicators.
3. **Temporal Patterns** – Explores travel-time and speed patterns across different times of the day and transport modes.

## Tools Used

- Power BI Desktop
- Power Query
- DAX

## Data Note

The dashboard uses simulated data consisting of 200 trip records across five transport modes. The findings are illustrative and should not be interpreted as actual transport conditions in Dar es Salaam.
