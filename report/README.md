# Project Report

This folder contains the final written report for the project **Exploring Urban Transport Performance Through Data**.

## File

`urban_mobility_analysis_report.pdf`

## Report Overview

The report presents a descriptive analysis of selected urban transport modes using a simulated dataset representing Dar es Salaam, Tanzania, as its geographical context.

It is organised into the following sections:

1. Introduction
2. Data and Methodology
3. Results and Findings
4. Discussion
5. Limitations and Recommendations
6. Conclusion
7. References
8. Appendices

## Analytical Focus

The report examines:
- Average travel speed across transport modes
- Average travel cost and cost per kilometre
- Travel-time variability
- Travel patterns across different times of the day

## Data Note

The analysis uses 200 simulated trip records across five transport modes. The results are illustrative and do not represent actual measured transport conditions in Dar es Salaam.
